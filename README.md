# Pharmacy & Healthcare Inventory Billing System

## About the Project

The Pharmacy & Healthcare Inventory Billing System is a web-based application developed using ASP.NET MVC and C#. The system is designed to simplify pharmacy operations by managing medicine inventory, stock availability, billing, and healthcare-related records.

## Objectives

- Manage medicine information efficiently.
- Maintain inventory and stock records.
- Track medicine expiry dates.
- Simplify customer billing and sales management.
- Generate useful inventory and sales reports.

## Technologies Used

- **Framework:** ASP.NET MVC
- **Programming Language:** C#
- **Database:** Microsoft SQL Server
- **Frontend:** HTML, CSS, JavaScript, Bootstrap (as implemented)
- **Data Access:** Entity Framework / LINQ (if implemented)
- **Development Tool:** Microsoft Visual Studio

## Features

- Medicine inventory management
- Add, edit, view, delete, and search medicine records (as implemented)
- Stock quantity and availability tracking
- Medicine expiry monitoring (if implemented)
- Customer billing and sales records (if implemented)
- Inventory and sales reports (if implemented)
- Database integration

## Project Structure

- **Controllers:** Handle application requests and business logic.
- **Models:** Define application data and database entities.
- **Views:** Provide the user interface using Razor views.
- **Content:** Contains CSS and other styling resources.
- **Scripts:** Contains JavaScript resources.
- **Database:** Contains database scripts, if provided.

## Requirements

- Windows operating system
- Microsoft Visual Studio
- The .NET Framework version required by the project
- Microsoft SQL Server or SQL Server Express
- SQL Server Management Studio (optional)

## How to Run the Project

1. Clone or download this repository.
2. Open the solution file (`.sln`) in Visual Studio.
3. Restore the required NuGet packages.
4. Create or restore the database using the supplied SQL script, if available.
5. Configure the SQL Server connection string in `Web.config`.
6. Build the solution.
7. Run the application using IIS Express.

## Database Configuration

Configure your own local SQL Server database before running the application. Update the connection string in `Web.config` to match your local SQL Server instance and database name.

Do not commit database passwords, private credentials, or real patient information to GitHub.
